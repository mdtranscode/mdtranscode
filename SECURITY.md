# Security Policy

## Reporting a Vulnerability

Please do not publish an exploitable security issue before there is an opportunity to investigate it.

Send a concise report to:

    hello@mdtransco.de

Include the affected version, reproduction steps, impact, and any suggested mitigation you already have.

## Sensitive Material

Do not submit credentials, tokens, signing private keys, certificate passwords, account secrets, personal developer data, or machine-specific private information to the public repository.
